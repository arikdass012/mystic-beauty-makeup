# Mystic Beauty Makeup 🌟

**Full-stack MERN e-commerce platform** reselling luxury makeup brands (MAC, Sephora) at 30-50% discounts. Live demo with auth, cart, checkout, and 50+ products.

[![Vercel](https://vercel.com/button)](https://mystic-beauty-makeup.vercel.app)
[![Tests](https://github.com/yourusername/mystic-beauty-makeup/actions/workflows/test.yml/badge.svg)](https://github.com/yourusername/mystic-beauty-makeup/actions)

## ✨ Features
- **Responsive UI** - Tailwind CSS, mobile-first design
- **Product Catalog** - Filter/search by brand, price, category
- **User Auth** - JWT login/register/profile
- **Shopping Cart** - Add/remove/update quantities, localStorage sync
- **Mock Checkout** - Stripe Elements, order management
- **Admin Dashboard** - Product CRUD (demo mode)
- **Performance** - Lighthouse 95+, PWA capable

## 🛠 Tech Stack
